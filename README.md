# Apostolis Siatras — website

Public website files for Apostolis Siatras’s research portfolio.

Published with GitHub Pages from the `main` branch and repository root. The separate authoring project and research documentation remain private.

The site contains static HTML, CSS, JavaScript, fonts, images, and a bibliography. Relative URLs support this repository’s GitHub Pages project path.

Image and map credits are linked on the website; font license files are included in `assets/fonts/`. Third-party assets retain their respective rights.
